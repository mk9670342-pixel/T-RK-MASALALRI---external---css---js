# Dilden Dile Türk Masalları

## Proje Hakkında
Dilden Dile Türk Masalları, Anadolu ve Türk coğrafyasından seçilen 8 geleneksel masalı bir araya getiren tek sayfalık interaktif bir web projesidir. Kullanıcılar, sade ve anlaşılır bir arayüz üzerinden masalları inceleyebilir ve seçtikleri masalları okuyabilir.

## Projenin Amacı
Türk kültürüne ait geleneksel masalları dijital ortama taşıyarak kullanıcıların kolay ve keyifli bir şekilde masallara ulaşmasını sağlamak.

## Kullanılan Teknolojiler
- HTML5
- CSS3
- JavaScript

## Dosya Yapısı
Proje, HTML, CSS ve JavaScript kodları birbirinden ayrılarak üç farklı dosya şeklinde düzenlenmiştir.

- **index.html:** Web sayfasının temel HTML yapısını içerir.
- **style.css:** Sayfanın tasarım, renk ve biçimlendirme kodlarını içerir.
- **script.js:** JavaScript kodlarının bulunduğu harici dosyadır.

CSS ve JavaScript dosyaları HTML belgesine harici dosya bağlantıları kullanılarak eklenmiştir.

## Projenin Çalıştırılması
Projeyi çalıştırmak için `index.html` dosyasının bir web tarayıcısında açılması yeterlidir. CSS ve JavaScript dosyalarının doğru çalışabilmesi için üç dosyanın aynı klasörde bulunması gerekir.
